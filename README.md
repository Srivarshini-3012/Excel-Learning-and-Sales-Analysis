# Excel Learning and Sales Data Analysis

## Project Overview

This repository contains my Excel learning journey, starting from basic Excel concepts and progressing to advanced formulas, data analysis, PivotTables, charts, and dashboard creation.

As part of my Excel learning, I completed hands-on exercises, practice tasks, and a sales data analysis project using a real-world sales dataset.

## Topics and Concepts Covered

### 1. Excel Fundamentals
- Basic calculations and arithmetic operations
- Cell references
- Relative and absolute references
- Basic Excel functions
- IF function and logical operations

### 2. Excel Functions
- SUM, AVERAGE, MIN, MAX
- COUNT and COUNTA
- SUMIF
- IF, AND, OR
- LEFT, RIGHT, LEN and SEARCH
- CONCAT and CONCATENATE
- TEXTJOIN

### 3. Lookup Functions
- VLOOKUP
- XLOOKUP
- INDEX
- MATCH
- Combining INDEX and MATCH

### 4. Data Sorting and Filtering
- SORT
- SORTBY
- FILTER
- UNIQUE
- SEQUENCE
- RANDARRAY

### 5. Sales Data Analysis and Dashboard

Used a Vrinda Store sales dataset containing over 31,000 records to perform sales analysis using Excel.

**Analysis performed:**
- Order status analysis
- Sales analysis by gender and age group
- Sales performance by sales channel
- Top-selling product categories
- Monthly sales and order comparison
- Overall sales and profit analysis
- Dashboard creation using charts and PivotTables

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts and Excel charts
- Excel formulas and functions
- Data sorting and filtering

## Key Learning Outcomes

- Improved understanding of Excel functions and formulas.
- Practised data lookup and retrieval techniques.
- Learned to organise, sort, and filter datasets.
- Gained hands-on experience with PivotTables and charts.
- Developed skills in analysing sales data and presenting insights through visualizations.

## Repository Structure

- `Excel_Workbook/` – Excel exercises, practice tasks, and sales analysis.
- `Dashboard_Preview/` – Screenshots of the completed dashboard.
- `Project_Documentation/` – Project questions and supporting documentation.

## Conclusion

This project represents my practical learning experience with Microsoft Excel, from fundamental concepts to data analysis and dashboard development. It helped me understand how Excel can be used to organise data, analyse business performance, and communicate insights effectively.

**Learning by doing!**
